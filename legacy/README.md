# legacy/

This directory documents the **legacy experimental artifact**: the `demo-goose.iso`
file at the repository root.

- It is a 2011-era Chrome OS Linux / openSUSE 11.4 based live ISO (details in
  [`docs/legacy-iso-analysis.md`](../docs/legacy-iso-analysis.md)).
- It is **not** a GOOSE OS build and must **not** be presented or booted as one.
- It is preserved for historical reference and tracks under Git LFS.
- Modern GOOSE OS images, when produced, will be built separately on a maintained
  Linux base — see the [roadmap](../docs/roadmap.md).

Nothing in this directory is required to build or run the GOOSE OS prototype.
